# SQL Data Analysis Internship – Task 2

## 📌 Project Overview

This project extends the Student Management Database from Task 1 by adding Courses and Enrollments tables.

The project demonstrates the use of SQL joins, grouping, and aggregate functions for data analysis.

## 🗂️ Database Tables

### Students
- id
- name

### Courses
- id
- name

### Enrollments
- student_id
- course_id
- grade

## 🔍 SQL Analysis Performed

The following queries are included:

1. List all students enrolled in each course.
2. Find the average grade per course.
3. Find the top 3 students overall.
4. Count students who failed with a grade below 40.
